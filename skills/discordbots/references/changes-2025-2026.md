# Aktualisierung älterer 14.x-Bots + Discord-Plattform-Änderungen 2025–2026

Stand 2026-09-18. Quellen: discord.js 14.27.0-Tarball (`process.emitWarning`-Texte, `@deprecated` in
`typings/index.d.ts`), @discordjs/builders 1.14.1, discord-api-types 0.38.55, Discord-Changelog
(github.com/discord/discord-api-docs → `developers/change-log.mdx`).

## A. Deprecation-Cleanup (v14 → 14.27, macht zugleich v15-ready)
Erst `discord.js` auf `^14.27.0` heben (keine Breaking Changes innerhalb 14.x), dann mit
`node --trace-deprecation index.js` starten und die Treffer abarbeiten. Am häufigsten betroffen: `ephemeral: true`, `'ready'`, `WebhookClient`, `AttachmentBuilder` und `guild.commands.create()`.

| Alt (deprecated) | Neu | Seit | Such-Regex |
|---|---|---|---|
| `reply/deferReply/followUp({ ephemeral: true })` | `flags: MessageFlags.Ephemeral` (Runtime-Warnung) | 14.17 | `ephemeral:\s*true` |
| `reply({ fetchReply: true })` | `withResponse: true` → `res.resource.message`, oder danach `i.fetchReply()` | 14.17 | `fetchReply:\s*true` |
| `client.on('ready')` | `client.once(Events.ClientReady)` (Wert `'clientReady'`) | 14.22 | `on\(['"]ready['"]` |
| `'webhookUpdate'` | `Events.WebhooksUpdate` | 14.x | `webhookUpdate['"]` |
| `SelectMenuBuilder/-Component/-Interaction/-OptionBuilder`, `isSelectMenu()` | `StringSelectMenu*`, `isStringSelectMenu()` | 14.x | `\bSelectMenu(Builder\|Interaction\|Component\|OptionBuilder)\|isSelectMenu\(` |
| `.setDMPermission()`, `dmPermission` | `.setContexts(...)` (nur global relevant) | 14.x | `setDMPermission` |
| `bans.create(u, { deleteMessageDays })` | `{ deleteMessageSeconds }` | 14.x | `deleteMessageDays` |
| `messages.fetchPinned()` | `messages.fetchPins()` → `{ items: [{ message, pinnedAt }], hasMore }` | 14.22 | `fetchPinned\(` |
| `Emoji#url` | `emoji.imageURL()` | 14.x | `emoji\.url\b` |
| `pollAnswer.fetchVoters()` | `pollAnswer.voters.fetch()` | 14.23 | `fetchVoters` |
| `role.color` / `role.setColor()` | `role.colors` / `role.setColors({ primaryColor, secondaryColor? })` | 14.22 | `role\.(set)?[cC]olor\b` |
| `message.interaction` | `message.interactionMetadata` | 14.17 | `\.interaction\b` (manuell prüfen) |
| `i.sendPremiumRequired()` | Premium-Button (`ButtonStyle.Premium` + `setSKUId`) | 14.x | `sendPremiumRequired` |
| `Formatters.userMention()` usw. | direkte Imports `userMention`, `time`, … | 14.x | `Formatters\.` |

**Falle `clientReady`:** vor 14.22 war `Events.ClientReady === 'ready'`. Der **String** `'clientReady'`
feuert auf < 14.22 nie → immer die Enum-Konstante nutzen und die Version ≥ 14.22 halten.

## B. Discord-Plattform-Änderungen mit Code-Folgen
| Datum | Änderung | Konsequenz im Bot |
|---|---|---|
| angekündigt 2025-09-02, Pflicht **2026-03-01** | **DAVE (E2EE) für alle Voice-Calls** | nur DAVE-fähige Voice-Libs verbinden: `@discordjs/voice` ≥ 0.19 / py-cord ≥ 2.8 (→ `voice.md`) |
| 2025-10-01 voll aktiv | Request Guild Members **alle** (`query ''`, `limit 0`): **1× pro Guild pro 30 s** | `guild.members.fetch()` ohne Argumente wirft `GatewayRateLimitError` (@discordjs/util) → nicht pro Command/Event aufrufen; einmal beim Start oder gezielt `fetch(id)` / `fetch({ query, limit })` |
| 2026-02-23 | Permission-Splits: `PinMessages` (1<<51), `BypassSlowmode` (1<<52), Bots brauchen `CreateGuildExpressions` (1<<43) für Emoji/Sticker-Erstellung und `CreateEvents` (1<<44) für Events | Invite-Scopes/Rollen des Bots anpassen; `ManageMessages` reicht zum Pinnen nicht mehr |
| 2026-03-03 | Context-Menu-Commands: 15 pro Typ (vorher 5) | mehr User/Message-Commands möglich |
| 2026-04-14 | Forward nur mit Lesezugriff auf den Inhalt, sonst Fehler **160014** | `message.forward()` nur mit `MessageContent`-Intent bzw. Nachrichten, die der Bot lesen darf |
| 2026-06-10 | Privileged Intents: frei per Toggle **< 10 000 User**, ab 10 000 Review, danach **jährlich** neu beantragen | nur benötigte Intents (`GuildMembers`, `MessageContent`, `GuildPresences`) — Guide „You might not need a privileged intent" |
| 2026-07-16 | aufgelöste Channels in Interactions enthalten `app_permissions` | Bot-Rechte pro Channel ohne Cache prüfbar |
| 2026-08-12 → **HTTP Pflicht 2026-11-16** | **Channel-Obfuscation**: Channels ohne `ViewChannel` kommen per Gateway als `___hidden___` mit Flag `ChannelFlags.ChannelObfuscated` (1<<17); `GET /guilds/{id}/channels` lässt sie weg | Audit/Mirror-/Permission-Übersichts-Bots: versteckte Channels erkennen (`channel.flags.has(ChannelFlags.ChannelObfuscated)`) und dem User melden statt Daten zu erwarten; testen per Portal-Toggle *Private Channel Obfuscation* |
| 2026-09-03 | Default-Upload-Limit 20 MiB (vorher 10) | echtes Limit pro Interaction: `i.attachmentSizeLimit` |
| 2026-09-15 | Large-Bot-Sharding: `shard`-Param bei *Get Current User Guilds* Pflicht | nur für Bots mit Large-Bot-Sharding |

## C. Neue Features (14.17 – 14.27), kurz
- **Polls** (Perm `SendPolls`, nicht mit V2-Flag):
  ```js
  await channel.send({ poll: { question: { text: 'Pizza?' }, answers: [{ text: 'Ja', emoji: '🍕' }, { text: 'Nein' }],
    duration: 24 /* Stunden */, allowMultiselect: false, layoutType: PollLayoutType.Default } });
  await message.poll.end();                                   // oder channel.messages.endPoll(id)
  ```
  Stimmen-Events `Events.MessagePollVoteAdd/Remove` brauchen Intent `GuildMessagePolls`.
- **Forwarding**: `await message.forward(targetChannel)`; eingehend `message.messageSnapshots` und
  `message.reference?.type === MessageReferenceType.Forward` (Forward ist nicht crosspostbar).
- **User-installierbare Apps**: `setIntegrationTypes` + `setContexts`, `i.context`, `i.authorizingIntegrationOwners`
  → `commands-deploy.md`.
- **Voice-Messages senden** (14.27): Datei mit `AttachmentBuilder#setDuration(sek)` + `setWaveform(base64)`
  und `flags: MessageFlags.IsVoiceMessage`.
- **Sonstiges**: `RoleManager#fetchMemberCounts()` (14.27), Rollen-Gradienten `role.colors` (14.22),
  `GuildMemberManager#editMe()` (Nick/Avatar/Banner/Bio des Bots pro Guild, 14.23), Soundboard
  (`guild.soundboardSounds`, `voiceChannel.sendSoundboardSound()`, 14.19), `i.attachmentSizeLimit` (14.20),
  Entitlements/Subscriptions (14.17), `voiceServerUpdate`-Event (14.27).
